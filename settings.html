Narrative Agent（状态后端版 v0.5.0 · 只读）
本版是「只读状态后端」：不改写 prompt、不改写消息。 prompt 由 ST 与预设原样组装（破甲栈、输出格式、正则清洗都归预设所有）； 本插件只在生成结束后读取消息里的状态块 → 补齐缺项 → 写入聊天变量 na_state， 再由预设条目 {{getvar::na_state}} 在下一轮注入给模型。

历史窗口（本版不再生效）

窗口在 n ~ n+m 轮之间生长：涨到 n+m 后一次裁掉最早的 m+1 轮回到 n，让历史前缀保持稳定以提高缓存命中。

写作规则来源（本版不再生效）

本插件只负责「状态追踪」。文风、字数、句式黑名单等一律由预设提供，开启此项后会把预设里启用的写作规则带进 prompt。关闭则只按插件内置的最小规则写作。

Prompt 上限（本版不再生效）

整个 prompt 的字符上限（含世界书、历史、预设规则）。超出后按「世界书 → 最老历史」顺序自动裁剪。这是防「超长请求被 API 拒绝 / 断联」的保险，建议与模型的上下文长度匹配（40000 字符 ≈ 2.5 万 token）。

世界书（本版不再生效）

格式化条目（[TOOL:*] / [UI] / [initvar] / [mvu_update]）一律不注入。条目在初始化与每轮结束后预取，供下一轮同步拼 prompt 使用。

输出处理

开启后，每段正文后面会附上 10 项完整状态追踪（时间 / 区域 / 在场角色+BUFF / 不在场角色 / 处女膜状态 / 做爱次数 / 角色好感度 / 当前态度 / 身体外貌 / 重要记忆点），缺项会自动用上一轮补齐。关闭则只在后台存档、不在消息里显示。
